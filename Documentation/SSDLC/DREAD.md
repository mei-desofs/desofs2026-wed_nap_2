## Individual Threat DREAD Scoring

The category-level table above reflects the aggregate posture per STRIDE category. This section applies DREAD to each individual threat listed above, providing per-threat scores that can be used to prioritise remediation within a category.

Each score is anchored to: (1) the OpenL/OWASP Threat Dragon severity for that threat; (2) the relevant CWE and OWASP Top 10 2021 category; (3) analogous CVSS 3.1 base score ranges from the NVD. Per-dimension rationale is provided in the Justification column so scores can be defended at review.

### Scoring calibration

| Dimension | High (8–10) | Medium (5–7) | Low (1–4) |
|---|---|---|---|
| **D** — Damage | RCE / full credential exposure / platform-wide financial fraud | Single-user data exposure / degraded availability | Cosmetic / informational only |
| **R** — Reproducibility | Deterministic payload, 100% reliable | Requires session/token, mostly reliable | Race condition / environment-specific |
| **E** — Exploitability | AV:N AC:L PR:N (no auth, public endpoint, standard tools) | Valid account needed, known techniques | DB/physical/insider access required |
| **A** — Affected Users | All platform users or all transactions | All users of one role | Targeted single user |
| **Disc** — Discoverability | Visible in browser devtools / automated scanner | Requires source or schema review | Requires insider / physical access |
